# VOZDUKHAN SIMULATOR

Простой русскоязычный веб-чатбот с персонажами.

## Запуск

1. Открой файл `index.html` в браузере.
2. Выбери персонажа в выпадающем списке.
3. Пиши сообщения в чат.

## Что внутри

- `index.html` - интерфейс.
- `styles.css` - стили.
- `app.js` - логика персоналий и генерация ответов.
